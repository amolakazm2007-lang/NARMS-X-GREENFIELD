# Phase 2 Blueprint — Universal Product Surface (DESIGN ONLY)

**Status:** FORBIDDEN TO IMPLEMENT until the signed Phase-1 certificate exists.

Phase 2 is the product-expansion layer for a large universal application. It does not replace the Phase-1 control plane; it consumes its mission/job/event/evidence contracts.

Planned capability domains:
- universal chat and mission workspace;
- software/app/web/game creation workbench;
- repository and patch workflows;
- browser/computer-use missions with approval boundaries;
- document, spreadsheet, presentation and PDF production;
- research and knowledge workflows;
- local/cloud model routing and model registry;
- GPU/training jobs;
- media/image/video/audio workflows;
- Android build/device laboratory;
- data analysis and visualization;
- reusable tools, automations and user-defined workflows;
- artifact/version/evidence explorer;
- administration, observability, quotas and cost/compute governance.

Engineering rule: capabilities enter through explicit contracts and worker classes; no feature may bypass identity, policy, approvals, durable jobs, evidence, artifacts, audit, or fencing semantics established in Phase 1.
